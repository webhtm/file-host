How this works

1. Press New, set how much space the drive may use, and choose where its data lives.

2. Open the Devices tab and copy the 25-character code.

3. On your homepage, open Files → ⋮ → Switch drive → Add → webhtm FileHost and paste the code.

4. Leave this tab open. Clients reach it directly over WebRTC; a public MQTT broker is used only to exchange the initial connection details, and those are encrypted with a key derived from the code.

Storage note. Data kept in this browser is encrypted at rest with a key derived from the drive code. The code itself is stored in this browser so the drive can start unattended — anyone with access to this browser profile can read both.

Space note. A drive's maximum can never be set below what it is already using.
